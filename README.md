This is an SDL3 derived 2d game engine.  Why? Read on..

Twenty-odd years ago as an eager wannabe game developer, I wrote a game engine (who didn't?)

It had a lot of functionality including a thorough GUI system, optimised 2d rendering and 3d scene management but the part I was most excited about was the system of game module classes with automatic resource management and application flow.

The trouble was, it was all written around DirectX8-- so no cross-platform and no shaders. The codebase and my game projects got me a foot in the door with a renowned UK developer so it wasn't all bad :)

Over the last 20 years I've dabbled with the current stable of game engines and they're just not doing it for me (I do know this is a 'me problem' and not a 'them problem'.) Now we live in a world of Copilot and SDL3 I've decided to bring my old codebase back from the dead for a major 2d project I have ongoing.

I'd like to share the engine code with the world and hopefully we'll all end up with a simple, lightweight and robust environment in which to develop our games.

Demo's, examples and Youtube videos will all come in time.
